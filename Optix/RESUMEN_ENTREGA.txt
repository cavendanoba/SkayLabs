   $ cd d:\Documentos\Optix
   $ docker-compose up -d

   $ cd backend
   $ npm run dev
   
   Verá: "✓ Servidor Optix corriendo en puerto 3001"

   $ cd frontend
   $ npm run dev
   
   Se abrirá automáticamente: http://localhost:5173
